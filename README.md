# Engineering AI Intelligence

This public GitHub Pages repository contains Qian Li's monthly Engineering AI literature reviews.

**Intended live site:**
[sdliqian2021.github.io/engineering-ai-monthly-intelligence](https://sdliqian2021.github.io/engineering-ai-monthly-intelligence/)

The site uses the same homepage, archive, typography, and article presentation as Tire & Rubber Intelligence while preserving a different research scope:

- `reports/` contains complete monthly intelligence reports;
- the homepage lists reports from their front matter;
- the About page explains the open collection approach;
- no fixed Engineering AI taxonomy is imposed.

Each public story is presented as a short literature entry with its publication date, organization, neutral description, and direct source links. Detailed evidence assessment stays in the private research workspace. The human author explicitly decides when local website changes are committed and published.

GitHub Pages is intended to deploy from the `main` branch and repository root. Drafts, private candidate registers, coverage logs, open-question trackers, confidence assessments, and source-audit records do not belong in this repository.
